# Employee Management System - Spring Boot

A backend Employee Management System developed using Java and Spring Boot.
This project demonstrates Spring Boot application development, Maven,
REST API concepts, database integration, and unit testing.

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL
- Maven
- REST API
- JUnit

## 📌 Project Features

- Employee management
- REST API development
- MySQL database integration
- Spring Data JPA
- Maven dependency management
- Unit testing
- Layered application architecture
